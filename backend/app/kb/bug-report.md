# Bug reports
id: KB-BUG-01
category: bug

## How to report a bug
Ask the player for a short description, the steps to reproduce, the server name, the character name and a screenshot or video if possible.
> ko: 간단한 설명, 재현 순서, 서버명, 캐릭터명, 가능하면 스크린샷·영상을 받습니다.

## Items lost due to a bug
Lost items can be restored after the development team confirms the bug in the server logs. Restoration usually takes up to 5 business days. Do not promise restoration before the bug is confirmed.
> ko: 개발팀이 서버 로그로 버그를 확인한 뒤 아이템을 복구하며, 보통 영업일 5일 이내입니다. 확인 전에는 복구를 약속하지 않습니다.
