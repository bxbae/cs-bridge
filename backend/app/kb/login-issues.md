# Login and connection problems
id: KB-LOG-01
category: technical

## Cannot log in
Ask the player to check the server status page, update the game to the latest version, and clear the game cache in Settings > Storage. Error code 1002 means the client version is outdated.
> ko: 서버 상태 페이지 확인, 최신 버전 업데이트, 설정 > 저장공간에서 캐시 삭제를 안내합니다. 오류 코드 1002는 구버전 클라이언트입니다.

## Disconnects during play
Frequent disconnects are often caused by unstable Wi-Fi. Ask for the error code, device model and the time the issue occurred so the technical team can check server logs.
> ko: 잦은 접속 끊김은 대개 불안정한 Wi-Fi 때문입니다. 오류 코드, 기기 모델, 발생 시간을 받아 기술팀이 서버 로그를 확인합니다.
